---
title: Voice Picker
description: "Choose a voice, hear a sample and set the speed, with a unique swatch per voice."
component: voice-picker
category: agents
tags: [voice, tts, picker, speed]
---

Compose `VoicePickerSelect`, `VoicePickerSample` and `VoicePickerSpeed` inside `VoicePicker`. Report
the sample's progress with `sample`; the button spins while it is made and becomes stop while it
plays. Each voice's swatch is built from the theme's chart colours, so it follows any palette.
