Wrap each `Testimonial` in a `TestimonialSectionItem` inside a `TestimonialSectionList`.

- `masonry` packs quotes of any length into columns; `bento` lines them up in a grid.
- Mark one item `featured` for a larger quote; in `bento` it spans a 2x2 block.
