Baby UI is a registry, not a package. The shadcn CLI copies each component's source into
your project. You own the files.

## What you get

- The same component in React and in Svelte, written by hand against one spec.
- One token layer, so both ports look identical without per-port tuning.
- shadcn part names and `data-slot` values on base components, so they replace shadcn/ui
  files without touching call sites.
- A JavaScript route for every component, with the types stripped at build time.

## Where to start

1. [Installation](/docs/installation)
2. [Theming](/docs/theming)
3. Any component page: pick a framework and language in the header, then copy the command
   from its Install tab.
