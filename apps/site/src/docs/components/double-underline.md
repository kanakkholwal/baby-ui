A hover-driven inline mark, not a standalone block -- drop it around a word inside a
sentence and it inherits the surrounding text's size and line-height.

## `trigger="always"` for a permanent double rule

Most uses want the reveal-on-hover default. `always` keeps both strokes on, for a
permanently double-underlined label.
