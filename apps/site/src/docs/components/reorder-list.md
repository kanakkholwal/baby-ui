Alt with the arrow keys moves the focused item. Each handle states that in its accessible
name, because a drag handle with no instructions is an unlabelled button to anyone not
using a mouse.

Drag and drop is the accelerator. It was built second, on purpose: a list that can only be
reordered by dragging cannot be reordered at all by a large number of people.
