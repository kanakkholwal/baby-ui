tags: [text, typing, typewriter, cursor]
---

Different purpose from `StreamingText`/`ResponseStream` (agents category): those track a
live chat token stream with a caret on the last real character. This is a decorative
typewriter effect for headings and hero copy, with no relationship to actual streamed
data -- `repeat` erases and retypes on a loop by design.
